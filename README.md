# 💊 Pharma Intelligence Analytics | SQL & Power BI



## 📌 Project Overview

This project focuses on analyzing a large-scale **pharmaceutical and healthcare dataset** using **MySQL and Power BI**. The analysis covers multiple dimensions of the pharmaceutical industry, including disease burden, pharmaceutical company financial performance, drug approvals, clinical trials, and biotech funding.

The project demonstrates an end-to-end analytics workflow — from **data validation and SQL-based analysis to KPI development and interactive Power BI visualization**.

---

## 🎯 Objectives

* Analyze healthcare and pharmaceutical industry trends
* Evaluate pharmaceutical company performance
* Understand disease burden using DALYs
* Analyze drug approval patterns across therapy areas
* Evaluate clinical trial performance and success rates
* Analyze biotech funding and investment trends
* Develop meaningful KPIs for executive-level analysis
* Present insights through interactive Power BI dashboards

---

## 🗂️ Dataset Structure

The project contains five major analytical datasets:

| Dataset                       | Key Analysis                                         |
| ----------------------------- | ---------------------------------------------------- |
| `disease_burden`              | Disease burden, DALYs, regions and yearly trends     |
| `pharma_companies_financials` | Revenue, R&D spending, operating margin and pipeline |
| `drug_approvals`              | Drug approvals, therapy areas and blockbuster drugs  |
| `clinical_trials`             | Trial phases, outcomes, enrollment and success rates |
| `biotech_funding`             | Funding deals, deal values and mega-deals            |

The SQL database includes fields such as revenue, operating margin, R&D expenditure, pipeline size, DALYs, therapy area, clinical-trial outcomes and biotech deal values.

## 🔍 SQL Analysis

SQL was used extensively to explore, validate, aggregate and analyze the datasets.

### Data Quality Checks

Performed:

* Missing-value analysis
* Duplicate-record detection
* Negative-value validation
* Year/date range validation
* Distinct-value analysis
* Record-count verification

For example, the project checks missing values across important fields such as disease, region, revenue, R&D expenditure, therapy area, trial phase and clinical-trial outcomes.

### Exploratory Analysis

The analysis includes:

* Disease burden by year, disease and region
* Pharmaceutical company revenue
* Pharmaceutical R&D expenditure
* Average operating margins
* Drug approvals by therapy area
* Clinical trials by phase
* Clinical trial success rates
* Biotech funding by year and deal type

---

## 📊 Key Analytical Areas

### 1. Disease Burden Analysis

Analyzed disease burden using **DALYs (Disability-Adjusted Life Years)**.

Key analysis:

* Yearly disease burden trends
* Disease-level comparisons
* Regional comparisons
* Total DALYs

SQL views were created to support yearly, disease-level and regional disease-burden analysis.

---

### 2. Pharmaceutical Company Performance

Evaluated pharmaceutical companies using:

* Total Revenue
* Total R&D Spending
* Average Operating Margin
* Average Pipeline Size

A dedicated SQL view was created to consolidate company-level performance metrics.

---

### 3. Drug Approval Analysis

Analyzed:

* Number of drug approvals
* Approvals by therapy area
* Blockbuster drugs
* Mega-blockbuster drugs

A SQL analytical view was created to summarize approvals and blockbuster-drug counts by therapy area.

---

### 4. Clinical Trial Analysis

Analyzed clinical trials based on:

* Trial phase
* Therapy area
* Successful trials
* Failed trials
* Overall success rate

The project calculates trial success rates using SQL and provides therapy-area-level performance analysis.

---

### 5. Biotech Funding Analysis

Analyzed biotech investment activity through:

* Total number of deals
* Total deal value
* Funding trends by year
* Mega-deals

A dedicated SQL view was developed to track yearly biotech funding activity.
